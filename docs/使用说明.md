# Kill the C · 使用说明

> 一款轻量的 Windows 系统盘清理工具 ｜ 安装包仅 5 MB ｜ 界面简约、操作可逆

---

## 一、安装与卸载

### 安装

1. 双击 **KillTheC-Setup.exe**
2. 确认安装位置（默认 `C:\Users\<用户名>\AppData\Local\Programs\KillTheC`，点「更改…」可换）
3. 需要桌面快捷方式就保持「创建桌面快捷方式」勾选
4. 点 **开始安装** → 完成后可点「立即运行」

安装位置在用户目录下，**全程不需要管理员权限**，也不会弹 UAC。

> 批量部署 / 无人值守：`KillTheC-Setup.exe /S`（可加 `/D=D:\Apps\KillTheC` 指定目录）

### 卸载

任选其一：

- **设置 → 应用 → 已安装的应用 → 找到「Kill the C 磁盘清理专家」→ 卸载**
- 控制面板 → 程序和功能 → 同上
- 直接运行 `"<安装目录>\KillTheC.exe" --uninstall`

卸载会移除程序文件、桌面与开始菜单快捷方式、注册表记录。
卸载界面上有一个「同时删除个人配置」选项，勾上会一并删掉白名单与界面偏好。

> 静默卸载：`"<安装目录>\KillTheC.exe" --uninstall --silent`

### 清理模式

| 模式 | 特点 | 适用场景 |
| --- | --- | --- |
| **轻度清理** | 只找出**明确安全**的系统垃圾：临时文件、浏览器缓存、日志、转储文件 | 日常维护，每天都能跑 |
| **深度清理** | 额外纳入系统更新缓存、Windows.old、备份文件、安装包缓存、大文件（≥32 MB），并把卸载残留与重复文件一起考虑 | C 盘空间告急时 |

切换模式会立即影响「扫描范围」提示与「选中全部安全项」的自动勾选范围。
深度模式不会自动勾选高风险的类目，仍需你手动确认。

### 关于流畅度

清理清单动辄上万条文件，界面采用**只渲染可视区域**的方式展示列表
（滚动时动态换页），并且勾选、展开等操作只更新受影响的那几处，
不会整页重绘。实测勾选一个类目约 1 毫秒、切换功能页 10 毫秒出头。

### 深浅色主题

右下角开关一键切换，默认浅色（苹果式白灰），深色为石墨黑。选择会被记住。

## 三、磁盘清理

### 1. 扫描

选择磁盘（默认 C 盘）→ 点 **开始扫描**。

扫描过程会实时显示：当前处理的文件名、已扫描数量、已读取体积、耗时。
**扫描只统计、不修改、不删除任何文件**，可以随时点「停止」中止。

C 盘 55 万个文件、80 GB 的实测耗时约 **22 秒**。

### 2. 看结果

扫描完成后，内容按**类目**分组呈现，每个类目都带三个关键信息：

- **体积与文件数**：这一类共占多少空间
- **优先级徽标**：`P0` 立即可清理 → `P1` 建议清理 → `P2` 视情况 → `P3` 保守不清理
- **风险徽标**：
  | 徽标 | 含义 | 建议 |
  | --- | --- | --- |
  | 🟢 安全 | 删除不影响系统与个人数据 | 可放心清理 |
  | 🟡 谨慎 | 可能影响使用体验或含个人数据 | 看一眼再决定 |
  | 🔴 高风险 | 可能是程序或系统组件 | 确认后再清 |

点类目行右侧箭头可展开，查看该类目下体积最大的文件清单，
列表可按**按大小 / 按数量 / 按优先级**排序。

### 3. 选择要清理的内容

两种方式，可以混用：

| 方式 | 操作 | 后端行为 |
| --- | --- | --- |
| **整类清理** | 勾选类目左侧的复选框 | 清理该类目下**全部**匹配文件（不受列表展示条数限制） |
| **精确清理** | 展开后勾选具体某个文件 | 只清理这几个文件 |

常用按钮：
- **选中全部安全项** — 一键勾选所有风险等级为「安全」且体积大于 0 的类目
- **清空选择** — 取消所有勾选
- **执行清理** — 进入确认环节

> 💡 如果某个类目右上角标注「仅展示体积最大的前 N 项」，说明该类目文件太多，
> 列表只展示了一部分。此时勾选类目本身（而不是逐条勾选）才会清干净整类。

### 4. 二次确认

点「执行清理」后会弹出确认框，展示：

- 将要清理的**项目数量**与**预计释放空间**
- **删除方式**二选一：
  - **移入回收站（推荐）** — 可随时还原
  - **永久删除** — 立即释放空间，无法恢复
- 完整的类目清单（带风险徽标）与文件清单
- 一个**必须勾选**的确认项：「我已核对以上内容，确认执行清理」

勾选后才能点「确认清理」。

### 5. 执行与收尾

清理过程会显示环形进度、当前处理的文件全路径、已处理数量、已释放体积、耗时，
可随时点「停止」。

完成后会给出结果小结（成功 / 失败 / 跳过 / 释放空间 / 耗时）。

**如果用的是「移入回收站」，结果页会出现「一键清空回收站」按钮** ——
因为此时文件只是从原位置消失，磁盘空间还没真正释放。点它→ 再次弹窗确认（需输入「清空」二字）
→ 才真正释放空间。

## 四、残留扫描

用于找出**已经卸载或删除的应用留下的文件**。

1. 选择磁盘 → 点 **开始扫描残留**
2. 程序通过注册表的「已安装应用清单」反向比对磁盘目录，
   找出「没有任何已安装应用认领」的文件夹

结果中每一项都带：

- **置信度**：高置信 / 中置信（低置信的不会展示，避免误报）
- **类型**：漫游数据、本地数据、程序数据、用户安装目录、注册表孤儿项、失效快捷方式、非系统盘根目录
- **判断依据**：例如「目录名未匹配到任何本机已安装应用」「包含应用缓存 / 配置等典型残留文件」
  「超过 120 天未被修改」「卸载记录指向的安装目录已不存在」
- 体积与文件数，以及「定位」按钮（直接在资源管理器中打开）

### 默认勾选策略

扫描完成后**自动勾选所有高置信项**，中置信项需要你自己判断。
每一个都可以点「定位」到资源管理器里看一眼再决定。

### 清理残留

点 **彻底清理** → 确认框会：

- 列出将删除的路径与体积
- 若包含程序目录下的高风险项，给出红色警示
- 要求勾选「我已确认这些内容确实属于已卸载的应用」
- **要求手动输入 `DELETE`** 才能执行

确认后执行**永久删除**（不经过回收站，因为残留目录通常体积大且无保留价值）。

## 五、重复文件清理

1. 选择**扫描范围**与**最小文件体积** → 点 **开始查找重复文件**

   | 扫描范围 | 说明 |
   | --- | --- |
   | **整个系统盘**（默认） | 扫描整个 C 盘，系统保护区与白名单自动跳过 |
   | **个人目录** | 只扫桌面 / 文档 / 下载 / 图片 / 视频 / 音乐，速度更快 |

   最小体积可选 ≥1 MB / 10 MB / 50 MB / 100 MB，默认 1 MB（越小的文件越容易产生无意义的重复项）。

2. 会自动跳过这些位置：`Windows`、`Program Files`、回收站、系统卷信息、
   UWP 应用数据（`AppData\Local\Packages`）、`node_modules`、`.git`、白名单目录。
   它们要么不可清理，要么属于「本来就该有多份」的目录。

3. 结果按「可释放空间」从大到小排列，每组显示：文件名、路径、副本数量、
   单个大小、可释放空间

> ⏱ **整盘扫描需要逐个读取文件内容进行比对，文件多时可能需要几分钟。**
> 过程中有实时进度，可随时点「停止」，也可以先切回「个人目录」范围快速扫一遍。
> 结果超过 600 组时只列出可释放空间最大的部分，界面上会给出提示。

### 保留哪一份？

每组默认**保留修改时间最早**的一个（通常是原始文件），
其余副本自动被选中。如果某个组的保留项不合适，可以在展开的列表里用左侧单选按钮改选，
改选后该组的选中状态会自动重算。

### 删除

- **一键选中所有重复文件**：选中所有组的全部非保留副本
- **取消全选**
- **删除选中**：弹出确认框（列出前 16 条路径、总数、可释放空间，需勾选确认）
  → 删除到回收站 → 结果页提供「一键清空回收站」

## 六、白名单

**被加入白名单的文件夹，在任何扫描和清理中都不会出现，也不会被删除。**

添加：点 **添加文件夹** → 在弹出的目录浏览器中逐层进入目标文件夹 → 点「将此文件夹加入白名单」
移除：在白名单列表里点「移出」

白名单保存在 `%APPDATA%\KillTheC\config.json`，同时作用于：

- 全盘扫描（跳过该目录及其所有子目录）
- 清理执行（**删除前再校验一次**，即使清单里出现了白名单内的路径也会被跳过）
- 重复文件扫描、残留扫描

> 建议把重要资料目录（例如正在做的项目文件夹、素材库）加入白名单，一劳永逸。

## 七、快捷操作：清空回收站

位置：「总览」页右侧的回收站卡片。

点击 **一键清空回收站** → 弹窗显示当前占用体积与项目数 →
需**输入「清空」二字**确认 → 执行 → 完成后提示释放了多少空间。

> ⚠️ 回收站里除了本工具刚删的文件，也可能有你之前手动删除的文件，
> 清空前请确认里面没有还需要的东西。

## 八、权限说明

界面左下角显示当前运行权限：

- **普通权限** — 可以清理用户目录下的临时文件、缓存、日志、回收站等；
  系统目录（`C:\Windows\Temp`、更新缓存）会因为权限不足而删除失败（结果里会列出原因）
- **管理员权限** — 可清理全部区域

点「提权」按钮 → 确认 → 系统弹出 UAC 窗口 → 允许后程序以管理员身份重启（当前窗口关闭）。
原来的扫描结果不会保留，需要重新扫描。

## 九、常见问题

**Q：扫描要多久？会不会很卡？**
A：C 盘 55 万文件约 22 秒，SSD 上基本全速。扫描过程中界面实时更新，可以随时停止，
期间不会修改任何文件。机械硬盘或文件数特别多时会慢一些。

**Q：为什么有些文件删除失败？**
A：常见原因有两个——① 权限不足（点「提权」后重试）；② 文件正被程序占用
（先关掉相关程序）。失败清单会在结果页列出。

**Q：为什么扫描后回收站那一项的数字不是我刚删的量？**
A：回收站类目统计的是**整个回收站**的占用，包含你之前手动删除的文件。

**Q：清理后空间没变化？**
A：默认删除方式是「移入回收站」，文件还在磁盘上。在结果页点「一键清空回收站」才会真正释放。

**Q：重复文件扫描要多久？**
A：默认扫描整个系统盘，需要逐个读取文件内容比对。文件多时要几分钟，
过程中有进度条与「停止」按钮；只想快速扫一遍个人资料可以切换成「个人目录」。

**Q：为什么某些看起来重复的文件没有列出来？**
A：`Windows`、`Program Files`、回收站、UWP 应用数据、`node_modules`、`.git`
这些位置被主动跳过了——它们要么不可清理，要么本来就该有多份（比如每个项目各自的依赖）。
小于设定体积的文件也不参与比对。

**Q：残留扫描会不会误删还在用的程序？**
A：低置信度结果不会展示；高置信项才默认勾选，且每一项都可以「定位」到资源管理器核对。
清理时需要额外勾选确认并输入 `DELETE`，是三道闸门。但**最终还是需要你确认**——
看到不认识的名字，建议先定位看一眼、或直接取消勾选。

**Q：程序打不开 / 白屏？**
A：本程序界面依赖系统自带的 **Microsoft Edge WebView2 运行时**（Win10/11 默认已装）。
若确实缺失，程序会自动降级用 Edge 窗口承载界面；两者都不可用时请到微软官网安装
「WebView2 Runtime」（Evergreen 版）。

**Q：能在 Windows 7 上用吗？**
A：不能。支持 Windows 10 1809 及以上 / Windows 11（x64）。

**Q：桌面快捷方式的图标显示成白页了？**
A：安装程序已经在结束时主动通知系统刷新图标缓存，正常情况下会立即显示正确图标。
如果仍显示旧图标，按 `Win+R` 运行一次 `ie4uinit.exe -show`，或重启一下资源管理器即可。

**Q：想重置所有设置？**
A：删除 `%APPDATA%\KillTheC\config.json` 即可（白名单与主题偏好会恢复默认）。

## 十、安全设计一览

| 关卡 | 说明 |
| --- | --- |
| 1. 扫描只读 | 扫描阶段不修改、不删除任何文件 |
| 2. 分级风险 | 每个文件都有风险等级；系统保护区（`System32`、`WinSxS` 等）永远不可勾选 |
| 3. 白名单优先 | 扫描与删除两个环节都会校验白名单 |
| 4. 二次确认弹窗 | 每次清理都弹窗列出数量、体积与清单，必须勾选确认 |
| 5. 永久删除强化确认 | 永久删除还需**手动输入确认词**（残留清理需输入 `DELETE`） |
| 6. 回收站兜底 | 默认删除方式是移入回收站，可随时还原 |
| 7. 清空回收站再确认 | 清空回收站需输入「清空」二字 |
| 8. 执行前复核 | 后端在真正删除前会重新检查白名单、受保护路径、盘符根目录、关键系统目录 |

完整的界面截图见 `docs/images/`。

**一句话原则：本工具不会在你没点确认的情况下删除任何东西。**
